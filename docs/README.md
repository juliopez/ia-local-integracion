# Portal educativo de Inteligencia Artificial Local

Este directorio contiene una interfaz web estática para la obra **Inteligencia Artificial Local: Diseño, Integración y Automatización de Soluciones con LLM**.

## Estructura
- Inicio y presentación: `index.html`
- Cinco volúmenes: `biblioteca.html`
- Secuencia pedagógica: `aprendizaje.html`
- Guías prácticas: `laboratorios.html`
- Proyecto integrador: `proyecto.html`
- Scripts y anexos: `recursos.html`
- Estilos y menú: `assets/`

## GitHub Pages
Publicar desde rama `main`, directorio `/docs` en Settings → Pages (si GitHub permite esa fuente) o mediante un workflow de Pages. URL prevista: https://juliopez.github.io/ia-local-integracion/

El sitio no ejecuta Ollama ni servicios externos. Enlaza a los contenidos originales en la rama `main` para mantener un único origen editorial, y muestra las portadas del repositorio desde rutas relativas `../images/`. **Nota de publicación:** GitHub Pages con fuente `/docs` incluye su contenido, pero no incluye automáticamente carpetas hermanas como `images/`. Las portadas deben utilizar URLs absolutas de GitHub, o copiarse al directorio publicado, antes de desplegar.

## Preservación
Los manuales, laboratorios, scripts, imágenes y metadatos originales permanecen intactos. Las fechas y versiones bibliográficas del repositorio se conservan para garantizar su citación; la navegación pública es atemporal.

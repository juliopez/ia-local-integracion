# Capítulo 7

# Versiones de software utilizadas

---

## Objetivo

Documentar las versiones del software utilizadas durante el desarrollo del taller, proporcionando una referencia para reproducir el entorno de trabajo, facilitar futuras implementaciones y mantener la compatibilidad entre los distintos componentes de la solución.

Las versiones registradas en este capítulo corresponden al entorno utilizado durante el desarrollo del taller y sirven como referencia para reproducir las actividades descritas en la colección.

---

# Cómo utilizar este capítulo

Antes de iniciar la configuración de la solución se recomienda verificar que las versiones instaladas en el equipo sean compatibles con las aquí documentadas.

En caso de utilizar versiones diferentes, se sugiere realizar pruebas de funcionamiento antes de desarrollar el Proyecto Integrador.

# V7.6

# Recomendaciones para futuras actualizaciones

---

Las herramientas utilizadas durante este taller evolucionan permanentemente.

Antes de actualizar cualquier componente se recomienda:

- revisar la documentación oficial;
- verificar la compatibilidad con los demás componentes del sistema;
- realizar pruebas en un entorno de desarrollo;
- respaldar la configuración existente;
- documentar las modificaciones realizadas.

---

# Lista de verificación

Antes de iniciar las actividades de integración técnica, confirme que dispone de:

| Verificación                     | Estado |
| -------------------------------- | :----: |

| Ollama instalado                 |   □    |

| Navegador compatible disponible  |   □    |

---

# Buenas prácticas

- Mantener un registro actualizado de las versiones utilizadas.
- Evitar combinar versiones incompatibles durante el desarrollo.
- Documentar todas las actualizaciones relevantes.
- Probar el funcionamiento completo del sistema después de cada actualización.
- Conservar un respaldo del entorno de trabajo cuando sea posible.

# Cierre del Manual de Referencia Técnica

El presente Manual de Referencia Técnica reúne los principales recursos de consulta utilizados durante el desarrollo de la colección **Desarrollo de Soluciones Organizacionales mediante Inteligencia Artificial Local**.

Su propósito es complementar los demás volúmenes mediante información técnica de consulta rápida, facilitando la configuración, el mantenimiento y la evolución de las soluciones desarrolladas.

En conjunto con el **Libro del Participante**, el **Manual Técnico**, el **Cuaderno de Laboratorios** y el **Manual del Proyecto Integrador**, este documento conforma una colección integrada que aborda el proceso completo de diseño, configuración, documentación y aplicación de soluciones organizacionales apoyadas por Inteligencia Artificial Local.

Se espera que este volumen continúe siendo una herramienta de consulta útil durante futuros desarrollos, permitiendo mantener la coherencia técnica y metodológica de los proyectos desarrollados a partir de esta obra.

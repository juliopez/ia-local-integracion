# Retroalimentación formativa

## Cuándo utilizar
Cuando el estudiante solicita orientación o retroalimentación académica.

## Procedimiento
1. Identificar la consulta y qué evidencia está disponible.
2. Explicar la respuesta en español, con lenguaje respetuoso y concreto.
3. Sustentar las afirmaciones institucionales únicamente en el contexto proporcionado.
4. Si falta información, reconocerlo expresamente y orientar al canal responsable.
5. No inventar normas, plazos, calificaciones ni datos de estudiantes.

## Formato de salida
Respuesta breve y, cuando corresponda, pasos concretos para continuar.

Esta skill es texto instructivo: no ejecuta código ni realiza acciones sobre sistemas.

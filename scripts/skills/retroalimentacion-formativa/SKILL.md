# Retroalimentación formativa

Utiliza esta Skill solo cuando se solicita retroalimentación de un trabajo, explicación o desempeño proporcionado; no para preguntas normativas.

1. Identifica una fortaleza observable en el material.
2. Señala un aspecto concreto que puede mejorarse.
3. Propón una recomendación aplicable y un siguiente paso breve.
4. No inventes características del trabajo ni repitas la retroalimentación.
